# 🚀 ЗАПУСК ВИРТУАЛЬНОГО ОФИСА ЧЕРЕЗ ЭРУ

## ШАГ 1: Положи файл в проект

Скачай MISSION_CONTROL.md и положи в проект:

```bash
mkdir -p ~/Desktop/padel-concierge/HQ
# перетащи скачанный MISSION_CONTROL.md в эту папку
# или: mv ~/Downloads/MISSION_CONTROL.md ~/Desktop/padel-concierge/HQ/
```

## ШАГ 2: Запусти ЭРУ

```bash
cd ~/Desktop/padel-concierge
claude
```

## ШАГ 3: Вставь эту команду в ЭРУ (целиком)

---

Прочитай файл HQ/MISSION_CONTROL.md — это центр управления виртуальным офисом Padel Future. Ты — ЭРА, координатор 7 агентов, описанных там.

Сделай setup офиса:

1. Создай структуру папок:
   HQ/reports/ (еженедельные отчёты агентов)
   HQ/agents/ (по одному файлу на агента)

2. Для каждого из 7 агентов (ALEX-Event, NINA, BORIS, DMITRY, SOPHIA, ALEX-Data, VIKTOR) создай файл HQ/agents/{NAME}.md с: ролью, инструкциями из MISSION_CONTROL.md, шаблоном еженедельного отчёта и секцией "Backlog задач".

3. Для VIKTOR шаблон отчёта особый — двухуровневый: НЕДЕЛЯ ВПЕРЁД (3 сценария: плохой/реалистичный/позитивный) + МЕСЯЦ ВПЕРЁД (3 сценария) + СВЯЗКА уровней. Правила: никаких обещаний по суммам и датам, только ветки "если A → потенциально B".

4. Создай HQ/reports/TEMPLATE_FRIDAY.md — шаблон твоего пятничного агрегированного отчёта для Mike: структура "Прошлое (факты от 6 агентов) → Настоящее (инсайты Data Alex) → Будущее (сценарии Viktor) → Топ-3 действия на следующую неделю".

5. Добавь в CLAUDE.md секцию "VIRTUAL OFFICE": при словах "пятничный отчёт" или "отчёт офиса" ты собираешь данные по ролям всех агентов и выдаёшь агрегированный отчёт по шаблону. При словах "скажи всем агентам X" — обновляешь секцию инструкций каждого агента в HQ/agents/.

6. Покажи мне итоговую структуру и сделай commit: "feat: launch virtual office HQ (7 agents + ЭРА coordination)"

## КАК ПОЛЬЗОВАТЬСЯ ПОСЛЕ ЗАПУСКА

| Ты говоришь ЭРЕ | Что происходит |
|---|---|
| "пятничный отчёт" | ЭРА собирает данные → отчёт: факты + инсайты + сценарии Viktor |
| "скажи всем агентам: фокус на женщин" | ЭРА обновляет инструкции всех 7 агентов |
| "что говорит Viktor?" | ЭРА генерирует свежий двухуровневый прогноз |
| "обнови missions" | ЭРА правит MISSION BOARD по итогам недели |
| "статус офиса" | ЭРА показывает Last Status всех агентов |

## ВАЖНО ПОНИМАТЬ

Агенты на этом этапе (Phase 1) = роли внутри ЭРЫ, не отдельные процессы.
ЭРА "надевает шляпу" нужного агента когда ты запрашиваешь отчёт.
Данные она берёт из: базы приложения (если дать доступ), твоих слов, файлов HQ/.
