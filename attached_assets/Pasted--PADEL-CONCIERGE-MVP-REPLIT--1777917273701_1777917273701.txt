СОЗДАЙ PADEL CONCIERGE MVP - ПОЛНЫЙ ПРОМПТ ДЛЯ REPLIT

=== ОБЗОР ПРОЕКТА ===
Создай премиальное веб-приложение для подбора соперников в паделе "Padel Concierge" которое автоматически предлагает партнёров, верифицирует уровень игроков и предоставляет аналитику игры. НЕ платформа бронирования — система контроля качества.

Философия: "Что можно анализировать — можно контролировать."

=== ТЕХНОЛОГИЧЕСКИЙ СТЕК ===
Backend: Node.js + Express
Frontend: React + Tailwind CSS
База данных: MongoDB (или Firebase)
Платежи: Stripe
Авторизация: JWT
Real-time: WebSockets для live доступности

=== РЕГИСТРАЦИЯ И ОНБОРДИНГ ПОЛЬЗОВАТЕЛЯ ===
Обязательные поля:
- Имя
- Email (с подтверждением)
- Телефон (WhatsApp)
- Уровень: D-, D, D+, C-, C, C+
- Цель: Играть / Тренироваться / Совершенствоваться
- Предпочтение интенсивности: Спокойная-Дружелюбная / Активная-Динамичная / Соревновательная / Тактическая-Шахматы
- Локация в Дубае (карта или ручной ввод)
- Календарь доступности (на 30 дней вперёд)

Интерфейс доступности:
- Сетка календаря (Пн-Вс, 4 недели)
- Клик по дню для выбора
- Перетаскивание временного диапазона (07:00-22:00)
- Несколько временных слотов в день допускаются
- Кнопка "Сохранить доступность"
- Показать "Последнее обновление: [время]"

=== АЛГОРИТМ УМНОГО ПОДБОРА ===
Когда пользователь открывает "Варианты матчей":
1. Группировка всех доступных игроков по временным слотам
2. Фильтр по уровню (максимальная разница ≤ 1 уровень)
3. Фильтр по интенсивности (одна категория)
4. Фильтр по локации (в пределах 5км если возможно)
5. Оценка комбинаций по баланс-скору
6. Вывод 4 вариантов:
   - Лучший матч (наивысший скор)
   - Сбалансированный (равные команды)
   - Сложный (сильные соперники)
   - Легкий (слабые соперники)

Для каждого матча показать:
- Дата + Время
- Название клуба (ближайший ко всем 4 игрокам)
- Подтверждено игроков: X/4
- Диапазон уровней: [мин-макс]
- Формат: [выбранный формат]
- Цена: 120 AED
- Статус: "Заблокирован - сначала верифицируй уровень" (для Лучшего матча) ИЛИ "Доступен - подтверди"

=== СИСТЕМА ВЕРИФИКАЦИИ УРОВНЯ ===
Перед доступом к "Лучшему матчу":
- Игрок должен сыграть 1 верификационный матч ИЛИ
- Игрок должен пройти 1 тренировку с тренером
- Показать попап: "Сыграй 1 верификационный матч чтобы разблокировать Лучшие матчи"
- Верификация = простая форма после матча: "Как ты сыграл?" (шкала 1-10)
- Тренер присваивает значок "верифицирован"

=== ФОРМАТЫ ИГРЫ (ОБЯЗАТЕЛЬНЫЙ ВЫБОР) ===
Перед подтверждением бронирования, игрок ДОЛЖЕН выбрать:

1. КЛАССИЧЕСКИЙ МАТЧ
   - Лучший из 3 сетов
   - Стандартная система подсчёта (0-15-30-40)
   - Тай-брейк при 6-6
   - Длительность: 90-120 мин
   - Рекомендуется: Уровень C и выше

2. УПРОЩЁННЫЙ МАТЧ
   - 2 сета до 6
   - Без преимущества в счёте (гланд-слэм при 40-40)
   - Тай-брейк при 6-6
   - Длительность: 75-90 мин
   - Рекомендуется: Все уровни (по умолчанию)

3. РОТАЦИОННАЯ ИГРА
   - Партнёры меняются каждые 15-20 мин
   - Игрок играет со всеми 3 другими
   - Счёт не ведётся
   - Социальный / тренировочный формат
   - Длительность: 60-80 мин
   - Рекомендуется: Новички и развлечение

Система автоматически выбирает формат по уровню:
- D-, D, D+ → Ротационная игра
- C-, C, C+ → Упрощённый матч
- Пользователь может переопределить

=== ОБЯЗАТЕЛЬНЫЙ ПРОТОКОЛ РАЗМИНКИ ===
После подтверждения бронирования, показать экран разминки:

Для игроков УРОВЕНЬ C+ И ВЫШЕ: ОБЯЗАТЕЛЬНО
Для игроков ниже C: РЕКОМЕНДУЕТСЯ

10-минутная структурированная разминка с видео-демо:
0-3 мин: Защита на линии (глубина, отправка мяча в глубину)
3-6 мин: Защита у стекла (отскоки, контроль высокого мяча)
6-8 мин: Игра с лета (чистые удары, мягкие руки)
8-10 мин: Смеш/Бандеха (агрессивные верхние удары)

UI показывает таймер + анимированный GIF для каждой фазы.

Игрок должен подтвердить: "Разминка завершена ✓"

Если ЛЮБОЙ игрок отказывается от разминки:
- Автоматическое удаление из этого матча
- Матч переопубликован с 3/4 игроками
- Приглашение отправляется следующему в листе ожидания
- Для принявших разминку: матч продолжается с ними

=== ПРАВИЛО ДЛЯ ОПОЗДАВШИХ ===
Показать чётко перед матчем:

"Правило для опоздавших
- 5-минутный льготный период
- После 5 мин: присоединяйся без разминки
- Частые опоздания: штрафы (в будущем)"

=== БРОНИРОВАНИЕ И ОПЛАТА ===
Процесс бронирования:
1. Выбрать матч из вариантов
2. Выбрать формат (если не по умолчанию)
3. Проверить: дата, время, клуб, игроки, цена (120 AED)
4. Нажать "Подтвердить и оплатить"
5. Страница оплаты Stripe (тестовый режим)
6. Подтверждение платежа
7. Добавить в календарь (кнопка Google/iCal)
8. Отправить подтверждение всем 4 игрокам (плейсхолдер WhatsApp-уведомления)

Плейсхолдер платежа: Stripe тестовые карты (4242 4242 4242 4242)

=== ПРОФИЛЬ И ПРОГРЕСС ===
Каждый игрок видит:
- Аватар + имя + значок уровня
- Сыграно матчей: [количество]
- Процент побед: [%]
- Прогресс-бар уровня: D- → D → D+ → C- → C → C+
- Следующая цель: [X побед до следующего уровня]
- Уверенность в текущем уровне: [%]
- Список избранных партнёров (сохранённые игроки)
  - Показать статус онлайна (зелёная точка)
  - Время последней активности
  - Следующий доступный слот
- Статистика:
  - Матчи по форматам (круговая диаграмма)
  - Тренд процента побед (график за 30 дней)
  - Самые частые партнёры

=== СИСТЕМА ВИДЕОАНАЛИЗА ===
Пользователь может:
1. Загрузить видеофайл (MP4, макс 50MB, до 10 мин)
2. Выбрать "Какой ты игрок?" по цвету футболки
3. Написать запрос: "Проанализируй мой удар слева" или открыть форму
4. Отправить на анализ
5. Видеть статус: "В ожидании / В процессе / Готов"
6. Получить уведомление когда готов (24-48 часов)

Анализ включает:
- Обложка (1 ключевой инсайт)
- Снимок (сильные стороны / слабые стороны)
- Основные метрики:
  - Качество решений (%)
  - Позиционирование (%)
  - Выбор удара (%)
  - Темп консистентности (%)
- Ключевые ошибки (топ 3)
- Распознавание паттернов ("Ты испытываешь трудности под давлением")
- Идентичность игрока ("Защитник")
- План действий (3 конкретных упражнения)
- Рекомендация по тренировке (рекомендация тренера)
- Путь развития (что дальше)

=== ПАНЕЛЬ УПРАВЛЕНИЯ ТРЕНЕРА (ОТДЕЛЬНЫЙ ВХОД) ===
Тренер видит:
- Всех игроков в системе
- Предстоящие матчи (тренер может присутствовать/верифицировать)
- Очередь видеоанализов (ожидание / назначены / доставлены)
- Доход: ежедневный / еженедельный / ежемесячный
- Статистика игроков: распределение по уровням, активность
- Производительность: время ответа на анализ

Тренер может:
- Отметить верификационные матчи
- Загрузить видеоанализ
- Отправить сообщение игрокам
- Видеть кто добавил тренера в избранные (будущих партнёров)

=== АДМИН-ПАНЕЛЬ (ВЛАДЕЛЕЦ МАЙК) ===
Real-time аналитика:
- Всего зарегистрировано пользователей (счётчик)
- Пользователей онлайн ПРЯМО СЕЙЧАС (live)
- Полный лог активности пользователей в реальном времени:
  * Кто зарегистрировался (время)
  * Кто забронировал матч (время)
  * Кто отменил
  * Кто загрузил видео
  * Кто произвёл оплату
  * Все обновления профиля
- Метрики доходов: ежедневно / еженедельно / ежемесячно итого
- Статистика матчей:
  * Создано
  * Подтверждено
  * Отменено
  * Завершено
- Очередь видеоанализа: ожидание / в процессе / доставлено / среднее время
- Топ игроки (по количеству матчей)
- Статус интеграции клубов (сколько клубов подключено)

Микровзаимодействия на уровне пользователя:
- Каждый игрок показывает "добавил X избранных игроков"
- Индикатор "X моих избранных онлайн сейчас"
- Лента активности: последний вход, последний матч, последняя загрузка видео
