## LEVEL CALCULATION LOGIC

Count correct answers in Q4–Q10:
- 7 correct → C+
- 6 → C
- 5 → C-
- 4 → D+
- 3 → D
- 0–2 → D-

Then **downgrade by one tier**:
C+ → C, C → C-, C- → D+, D+ → D, D → D-, D- stays D-

Save BOTH: quiz_level (before) and real_level (after downgrade)

## DATABASE SCHEMA

```sql
-- Users
CREATE TABLE users (
  id SERIAL PRIMARY KEY,
  name VARCHAR(100) NOT NULL,
  email VARCHAR(200) UNIQUE NOT NULL,
  phone VARCHAR(50),
  created_at TIMESTAMP DEFAULT NOW()
);

-- Quiz Results
CREATE TABLE quiz_results (
  id SERIAL PRIMARY KEY,
  user_id INTEGER REFERENCES users(id),
  quiz_level VARCHAR(5),      -- before downgrade
  real_level VARCHAR(5),      -- after downgrade
  q1_answer INTEGER,
  q2_answer INTEGER,
  q3_answer INTEGER,
  q4_answer VARCHAR(5),       -- yes/no
  q4_extra TEXT,              -- optional text
  q5_answer VARCHAR(5),
  q6_answer VARCHAR(5),
  q7_answer VARCHAR(5),
  q8_answer VARCHAR(5),
  q9_answer VARCHAR(5),
  q10_answer VARCHAR(5),
  personality_type VARCHAR(50),
  completed_at TIMESTAMP DEFAULT NOW()
);
```
