TASK 3 — Two-week court availability grid
==========================================

Create courts table linked to clubs:
- id, club_id FK, court_number, name, surface, indoor, active

Create court_availability table:
- id, court_id FK, date, start_time, end_time
- status (available / interest_logged / booked / blocked)
- price_aed, level_suitability (D-/D/D+/C-/C/C+/B-/any)
- added_by (user id), notes, created_at

Admin UI /admin/availability (mobile-first, daily operational tool):
- Pick club → see all its courts
- Calendar strip showing next 14 days
- Tap a day → grid of time slots per court
- Tap empty slot → mark "available" with price (quick entry)
- Tap available slot → toggle to "booked" or "blocked"
- Bulk actions (CRITICAL for Alexander's speed):
  · "Copy this day's slots to next week"
  · "Mark all 18:00-22:00 available for all courts this week"
  · "Block this weekend across club"
- Visual: available=green, interest_logged=amber, booked=gray, blocked=red

Speed-optimized — Alexander enters dozens of slots daily. Under 60 sec 
per evening of slots.

Player-facing on club detail page:
- "Свободные слоты" section, next 14 days
- Filter by date, time of day, price, level
- Player taps available slot → "Интересно" button → 
  sends Misha+Alexander notification "Игрок X заинтересован в слоте Y"
- Slot status changes to interest_logged
- Misha/Alexander coordinates booking with club, marks slot booked

NO auto-booking. NO auto-matching. Human curation only at this stage.

==========================================
TASK 4 — Personal progress metrics for players
==========================================

After every confirmed match or group training, optionally prompt player:
"Что ты хочешь зафиксировать после игры?"

Player picks 0-3 metrics from a curated list, OR writes their own custom:
- Серия побед
- Процент выигранных розыгрышей у сетки
- Матчи без unforced errors
- Стабильность подачи
- Количество удачных bandejas
- Количество удачных víboras
- Время реакции на mid-court
- Партнёрская синергия (1-10 self-rated)
- Уровень удовольствия от матча (1-10)
- [+ Custom: свободный текст]

Schema:
- player_metrics table: id, user_id, match_id (nullable), metric_name, 
  value (numeric), notes, recorded_at
- player_metric_preferences table: id, user_id, metric_name, active boolean

Player profile gets new "Мои метрики" section:
- Shows last 30 days of tracked metrics
- Simple line/bar charts per metric
- "Что меня делает гордым" — pinned metric, prominently displayed

Russian UI. Mobile-first. Optional (player can skip the post-match prompt).
